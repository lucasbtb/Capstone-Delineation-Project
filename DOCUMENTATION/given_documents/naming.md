Please upload your processed files only to the folder that corresponds to your assigned rater id (ex. 1a)
  
If you are unsure of your rater id, please refer to the Master Rater Table

Before uploading make sure your file is:

Is named following this format
SUBJECTID_SESSION_RATERID_manual_seg.nii.gz
Examples:
SUBC001_ses01_Rater1a_manual_seg.nii.gz
SUBC025_ses2_Rater4c_manual_seg.nii.gz
SUBG001_ses1_Rater2b_manual_seg.nii.gz

Is saved in NIfTI format (.nii.gz)
