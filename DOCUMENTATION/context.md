# Context

## Data — `DATA/` (not versioned)
- `DELINEATION_DATA/`: raw manual segmentations of the **thalamic nuclei**, 9 labels (1–9, 0 = background). Do not modify.
- `DELINEATION_CLEAN/`: cleaned delineations, one folder per scan (generated by `ANALYSIS/build_clean_data.py`).
- `STAPLE/`: one STAPLE reference delineation per scan (generated by `ANALYSIS/staple.py`).
- `sTHOMAS_FILES/`: sTHOMAS folders from the drive (empty for now).
- Base MRIs: available, to be added.

## Delineations
- Folder tree: `Group N/Rater Nx/SUB{C|G}###_ses#_RaterNx_manual_seg.nii.gz`
- **Group** = team of students (16). **Rater** = one student (a–k).
- `SUBC` = healthy control (HC), `SUBG` = glaucoma.
- Empty rater folder = work not handed in (86).
- Volumes: 192×224×224, 1 mm isotropic, RAS.

## Given documents — `DOCUMENTATION/given_documents/`
- `excel_delineation.xlsx`: master table of the raters (group, type HC/Glaucoma/Mixed, assigned scans). Contains names and emails.
- `colors.md`: colour of each nucleus, in the recommended delineation order.
- `naming.md`: file naming convention.
