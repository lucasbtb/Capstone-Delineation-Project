# Delineation Explorer

This should create a not numbered python program that opens a web page.
This web page  has a button to import delineations.
Multiple delineations can be imported.
The delineation is seen in the three views, labeled.
Navigating depth of each view can be done in the same vibe as ITK-snap.
It should be easy to differentiate the delineations from different files.
It should be easy to toggle on and off the 9 different nuclei.
